# Superstore Sales & Profitability Analysis

## Project Overview

This project analyzes retail sales and profitability data using SQL, MySQL, Microsoft Excel, Power BI, and DAX. It includes an interactive dashboard designed to explore business performance across product categories, sub-categories, regions, and time.

The goal is to demonstrate practical data analysis, SQL querying, KPI calculation, and dashboard development skills.

## Objectives

- Analyze sales and profit performance across categories and regions.
- Track key performance indicators such as total sales, total profit, total orders, profit margin, and average order value.
- Explore sales trends over time.
- Investigate differences in profitability across business segments.
- Present the analysis through an interactive Power BI dashboard.

## Tools & Technologies

- **SQL / MySQL:** Data querying, aggregation, filtering, and analysis.
- **Microsoft Excel:** Data inspection, preparation, and analysis.
- **Power BI:** Interactive dashboard development and visualization.
- **DAX:** Measures and KPI calculations.

## Key Business Questions

1. Which product categories contribute the most sales and profit?
2. How does performance differ across regions?
3. Which sub-categories are more or less profitable?
4. How do sales change over time?
5. What do the sales and profit metrics reveal about overall business performance?

## Key Performance Indicators

- Total Sales
- Total Profit
- Total Orders
- Profit Margin
- Average Order Value
